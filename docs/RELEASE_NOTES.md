The first downloadable iCalendify release. Select meeting details, generate an English title with on-device AI, review the event, and save to your chosen iCloud calendar.

### Install

1. Download **iCalendify-0.1.0-arm64.dmg** from the assets below.
2. Open it and drag **iCalendify** into **Applications**.
3. Open the app, click **Load calendars**, and allow Calendar access.

Requires **Apple silicon and macOS 26 or later**, with iCloud Calendar enabled. For AI titles, enable Apple Intelligence; manual entry also works without AI. No Xcode or Terminal is needed.

**This release is not Developer ID signed or notarized by Apple.** macOS may block the first launch. If you trust the download, try opening it, then use **System Settings → Privacy & Security → Open Anyway**. See [Apple's explanation](https://support.apple.com/102445).

### Use

Highlight text → right-click → **Services → Add to Calendar with iCalendify**. Check the title, year, date, time, and calendar before saving. You can also open the app and paste text.

AI processing stays on your Mac. Saved events and the selected text in their notes sync through iCloud. The download contains no personal calendar information or preferences.

[Help and privacy details](https://github.com/Alihjt/iCalendify/blob/main/docs/GUIDE.md) · [Report an issue](https://github.com/Alihjt/iCalendify/issues)

The `.sha256` file is an optional checksum; it is not needed to install the app. GitHub's **Source code** downloads are for developers.
