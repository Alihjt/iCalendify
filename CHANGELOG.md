# Changelog

## 0.1.0 — 2026-11-10

First downloadable release.

- Native macOS text Service and editable event preview.
- On-device AI titles in English, with no language picker.
- Runtime discovery of writable iCloud calendars, with a remembered selection.
- Locally hidden calendars and a custom iCalendify app icon.
- Date and location detection, manual editing, and visible ambiguity notices.
- On-demand app lifecycle, build/test scripts, and contributor documentation.
- Drag-to-Applications disk image, checksums, and automated GitHub releases.
